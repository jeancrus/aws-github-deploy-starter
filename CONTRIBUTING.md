# Contributing

Contribuições devem manter o projeto agnóstico de aplicação e conta AWS. Novos scripts precisam ser seguros por padrão, não imprimir secrets e ter modo de validação. `AGENTS.md` é a fonte canônica dos steerings.

## Pull Requests

O GitHub preenche automaticamente `.github/pull_request_template.md`. Mantenha as seções `Objetivo`, `Alteração`, `Motivo`, `Validação` e `Pós-merge`. Registre apenas validações realmente executadas e escreva `Nenhuma ação manual` quando não houver atividade após o merge.
